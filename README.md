# Dashboard Repository README

## Overview

This repository contains six interactive dashboards created using **Power BI** and **Google Looker Studio**. The dashboards were developed to analyze and visualize business data from different datasets. The aim of the dashboards is to help users understand trends, customer behaviour, sales performance, and business insights through visual reports.

### Dashboards Included

#### Power BI Dashboards

1. Shopping Trends Dashboard
2. Bright Coffee Shop Sales Dashboard
3. Retail Sales Dashboard

#### Google Looker Studio Dashboards

1. Shopping Trends Dashboard
2. Bright Coffee Shop Sales Dashboard
3. Retail Sales Dashboard

---

# Datasets Used

## 1. Shopping Trends Dataset

This dataset contains customer shopping information such as:

* Age
* Gender
* Item Purchased
* Purchase Amount
* Category
* Season
* Payment Method
* Review Rating
* Subscription Status
* Discount Applied
* Shipping Type

### Insights Found

* Female and male customers showed different purchasing behaviours.
* Some product categories generated higher sales than others.
* Customers using promo codes purchased more frequently.
* Seasonal trends affected customer spending patterns.

---

## 2. Bright Coffee Shop Sales Dataset

This dataset focuses on coffee shop transactions and sales performance.

### Insights Found

* Certain drinks and food items were sold more frequently.
* Peak sales occurred during busy customer hours.
* Payment methods influenced customer buying patterns.
* Monthly sales trends helped identify busy periods.

---

## 3. Retail Sales Dataset

This dataset contains retail transaction and customer sales information.

### Insights Found

* Sales performance differed across product categories.
* Customer purchasing trends changed over time.
* Some locations generated more revenue than others.
* Discounts affected total sales and customer purchases.
